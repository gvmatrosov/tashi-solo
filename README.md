# tashi-solo

Claude Code plugins by gvmatrosov.

```
/plugin marketplace add gvmatrosov/tashi-solo
```

| plugin | what it does | install |
|---|---|---|
| [tap2line](https://github.com/gvmatrosov/tap2line) | Stop paying Claude Code to search for code you can point at: tap any element in your running app — web, mobile, desktop — and its source line is on your clipboard. | `/plugin install tap2line@tashi-solo` |
| [autobuffer](https://github.com/gvmatrosov/autobuffer) | Everything Claude gives you to copy lands on your clipboard by itself — over SSH, through tmux, from a phone. | `/plugin install autobuffer@tashi-solo` |

Each plugin lives in its own repository, with its own README and license.
